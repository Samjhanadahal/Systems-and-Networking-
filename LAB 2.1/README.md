# LAB 2.1 – C Libraries, Linking, and ELF Executable Structure

## Overview

This lab explores C libraries, static and dynamic linking, and the ELF executable structure in Linux. Various Linux tools are used to compile, execute, and examine C programs and their library dependencies.

## Objectives

* Understand C standard libraries and header files.
* Compile programs using static and dynamic linking.
* Compare static and dynamically linked executables.
* Examine ELF headers and program segments.
* Identify shared library dependencies in Linux.

## Files

| File                          | Description                                         |
| ----------------------------- | --------------------------------------------------- |
| `procinfo.c`                  | C source program for displaying process information |
| `procinfo_dynamic`            | Dynamically linked executable                       |
| `procinfo_static`             | Statically linked executable                        |
| `dynamic_program_headers.txt` | Saved ELF program header information                |
| `Lab2_C_Linking_ELF.docx`     | Lab documentation and results                       |

## Tools Used

* GCC

## Key Topics
